# High-Trust Learning Resources — Fleet Data Platform

> Key primary sources, documentation, and technical reference standards.

## 1. Primary Documentation & Architecture Standards
* [Debezium PostgreSQL Connector Documentation](https://debezium.io/documentation/reference/stable/connectors/postgresql.html) — Log-based CDC WAL replication mechanism.
* [Apache Spark Structured Streaming Guide](https://spark.apache.org/docs/latest/structured-streaming-programming-guide.html) — Production streaming patterns, Watermarking, and Sink options.
* [Redis Geospatial Commands (GEOSEARCH)](https://redis.io/commands/geosearch/) — Redis GEO indexing and spatial radius searches.
* [Apache Airflow Concepts & TaskFlow API](https://airflow.apache.org/docs/apache-airflow/stable/core-concepts/index.html) — DAG dependencies and ExternalTaskSensors.
* [Kimball Group - Data Warehouse Toolkit](https://www.kimballgroup.com/data-warehouse-architecture/) — Dimensional Modeling, Star Schema, and SCD Type 2 standards.
