I. Cài đặt môi trường cho máy ảo kết nối nhau:

CHUẨN BỊ 3 MÁY ẢO, CÀI ĐẶT CÁC THÔNG TIN SAU : 
Khi setup ubuntu Cả 3 máy có hostname lần lượt là : master, slave1, slave2
Cài đặt 1 user chung cho cả 3 máy : aiguystory / 123456@@@

Hoặc có thể tạo user mới cho cả 3 máy : 
E.g:
sudo adduser hadoop
sudo usermode -aG sudo hadoop
su - hadoop


Lệnh kiểm tra xem user đã thuộc nhóm sudo chưa ? 
groups <user-name>


Nếu hostname chưa đúng ý, đặt lại hostname bằng lệnh sau : 
sudo hostnamectl set-hostname <hostname-mong-muốn>


1. Set cấu hình cho /etc/hosts trên cả 3 máy :
sudo nano /etc/hosts

Thêm các thông tin sau : 
ip-máy-master master
ip-máy-slave1 slave1
ip-máy-slave2 slave3

...


2. Xử lý trên máy master , cấu hình SSH không mật khẩu trên máy master:
sudo apt install openssh-server -y

ssh-keygen -t rsa -P "" -f ~/.ssh/id_rsa
ssh-copy-id <username>@master
ssh-copy-id <username>@slave1
ssh-copy-id <username>@slave2
...
ssh-copy-id <username>@slaveN


3. Test lại kết nối, không được hỏi mật khẩu:
ssh master date
ssh slave1 date
ssh slave2 date


4. Cài java 11 trên cả 3 máy
sudo apt install openjdk-11-jdk -y

Lấy đường dẫn java-home : readlink -f $(which java) # Thường là: /usr/lib/jvm/java-11-openjdk-amd64

5.1. Web UI
HDFS NameNode: http://master:9870
YARN ResourceManager: http://master:8088

Nếu không mở được từ Windows: thử bằng IP trực tiếp (http://<IP>:9870) trước. Nếu IP vào được mà tên master không vào được → thêm dòng <IP> master (và slave1, slave2) vào file C:\Windows\System32\drivers\etc\hosts trên Windows.
